# singlecell-CVAE

A conditional variational autoencoder (CVAE) that generates single-cell expression profiles of *Streptococcus pneumoniae* at a specified cefepime dose and exposure time.

## Model

![Model architecture](figures/model.png)

The encoder maps log1p(CPM) expression to a latent $z$. Dose and time are embedded separately and applied to $z$ through FiLM layers ($h = \gamma(c) \odot z + \beta(c)$), and the decoder maps $h$ back to expression. Because conditioning happens after sampling, new cells for any dose–time pair are generated by sampling $z \sim \mathcal{N}(0, I)$, applying the condition, and decoding.

Training minimizes

$$
\mathcal{L} = \text{MSE}(x, \hat{x}) + \beta \, D_{\text{KL}}\big(q(z \mid x) \,\|\, \mathcal{N}(0, I)\big) + \mathcal{L}_{\text{adv}}
$$

where $\mathcal{L}_{\text{adv}}$ is the MSE of linear regressors predicting dose and time from $z$. A gradient reversal layer (scale $\lambda$) trains the encoder to remove this information, so $z$ captures condition-independent cell state.

Defaults: hidden dim 256, latent dim 32, Adam (lr $10^{-3}$), batch size 16, 150 epochs, $\beta = 0.1$, $\lambda = 0.1$.

## Data

~80,000 *S. pneumoniae* scRNA-seq profiles across cefepime doses (multiples of MIC) and timepoints (0–4 h). Counts are CPM-normalized and log1p-transformed.

- **Test set:** all cells at 2× MIC, 2 h, held out to evaluate generation for an unseen condition.
- **Train/validation:** remaining cells, split 80/20.

Data is not included in this repository.

## Setup

```bash
git clone https://github.com/eddykang06/singlecell-CVAE.git
cd singlecell-CVAE
conda create -n singlecell-cvae python=3.11 -y
conda activate singlecell-cvae
pip install -r requirements.txt
```

Place data under `data/` (or set `DATA_DIR` to another location):

```text
data/
├── single_cell/          # One tab-separated genes × cells matrix per condition,
│                         # named by condition label (e.g. 2CEF2hr)
├── fcnts_timezero/       # Bulk RNA-seq featureCounts output (evaluation only)
└── CVAE_checkpoint.pt    # Written by 01-train, read by 02-eval
```

On Colab, the notebooks read from Google Drive instead.

## Usage

1. **`notebooks/01-train.ipynb`** — splits the data, trains the model, and saves a checkpoint.
2. **`notebooks/02-eval.ipynb`** — generates cells for the held-out condition, reports pseudobulk Pearson/Spearman correlation with real cells, compares pseudobulk to bulk RNA-seq, and plots the latent space.
